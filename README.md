# Gluteal / Thigh Nerve Guide — GitHub Pages

このフォルダは、GitHub Pagesの公開元にそのまま配置できる静的HTMLです。

## 公開手順

1. フォルダ内の `index.html` をGitHubリポジトリのルート、または `docs/` にアップロードする。
2. GitHubの **Settings → Pages** を開く。
3. **Deploy from a branch** を選び、ブランチと `/ (root)` または `/docs` を指定する。
4. 表示されたPages URLへアクセスする。

`index.html` がサイトの入口です。現在のHTMLには外部画像URL（NCBI、MDPI、Wikimedia）が含まれています。画像を安定して配信したい場合は、各出典のライセンス条件と出典表示を維持したうえで画像をリポジトリ内へ保存し、相対パスへ変更してください。
