# Gluteal / Thigh Nerve Guide — GitHub Pages

このフォルダは、GitHub Pagesでそのまま公開できるスタンドアロンHTMLです。

## 公開手順

1. このフォルダの内容をGitHubリポジトリのルート、または`docs/`へアップロードします。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、ブランチと `/ (root)` または `/docs` を指定します。
4. 表示されたPages URLへアクセスします。

`index.html`がサイトの入口です。主要な解剖図は`images/`に同梱しています。深殿部のMDPI図だけは原出典URLを参照しているため、公開環境の外部アクセス制限によって表示できない場合があります。

## 収録内容

- ダーク分析テーマ（キャンバス`#081416`、パネル`#102d31`、アクセント`#65d8d4`）

- 各図の出典リンクと、日本語ラベルを本資料用に付与した旨の注記
